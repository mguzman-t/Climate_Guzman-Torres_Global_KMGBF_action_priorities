How to interpret the maps

Agreement maps (%) show the proportion of ensemble members supporting a given result within each SSP-RCP scenario and connectivity radius. Each factorial ensemble contains 180 members, combining 2 taxon-specific connectivity outputs × 3 SDMs × 5 GCMs × 2 land-use models × 3 resistance responses. Higher agreement indicates that a result is supported more consistently across these sources of modelling uncertainty.
